# CoreWebView2MemoryUsageTargetLevel Enum

Specifies memory usage target level of WebView.

| Name |  Value | Description |
|--|--|--|
|`Normal` | 0x0  |  Specifies normal memory usage target level.|
|`Low` | 0x1  |  Specifies low memory usage target level. Used for inactive WebView for reduced memory consumption.|

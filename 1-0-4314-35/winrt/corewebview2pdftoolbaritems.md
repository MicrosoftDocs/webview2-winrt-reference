# CoreWebView2PdfToolbarItems Enum

Specifies the PDF toolbar item types used for the [CoreWebView2Settings.HiddenPdfToolbarItems](corewebview2settings.md#hiddenpdftoolbaritems) property.

| Name |  Value | Description |
|--|--|--|
|`None` | 0x0  |  No item. By default [CoreWebView2Settings.HiddenPdfToolbarItems](corewebview2settings.md#hiddenpdftoolbaritems) is equal to this value.|
|`Save` | 0x1  |  The save button.|
|`Print` | 0x2  |  The print button.|
|`SaveAs` | 0x4  |  The save as button.|
|`ZoomIn` | 0x8  |  The zoom in button.|
|`ZoomOut` | 0x10  |  The zoom out button.|
|`Rotate` | 0x20  |  The rotate button.|
|`FitPage` | 0x40  |  The fit page button.|
|`PageLayout` | 0x80  |  The page layout button.|
|`Bookmarks` | 0x100  |  The bookmarks button.|
|`PageSelector` | 0x200  |  The page select button.|
|`Search` | 0x400  |  The search button.|
|`FullScreen` | 0x800  |  The full screen button.|
|`MoreSettings` | 0x1000  |  The more settings button.|

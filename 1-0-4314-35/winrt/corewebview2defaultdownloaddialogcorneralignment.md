# CoreWebView2DefaultDownloadDialogCornerAlignment Enum

The default download dialog can be aligned to any of the WebView corners by setting the [CoreWebView2.DefaultDownloadDialogCornerAlignment](corewebview2.md#defaultdownloaddialogcorneralignment) property.
The default position is top-right corner.

| Name |  Value | Description |
|--|--|--|
|`TopLeft` | 0x0  |  Top-left corner of the WebView.|
|`TopRight` | 0x1  |  Top-right corner of the WebView.|
|`BottomLeft` | 0x2  |  Bottom-left corner of the WebView.|
|`BottomRight` | 0x3  |  Bottom-right corner of the WebView.|
